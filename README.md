## 🚀 Sobre o Projeto
O **Eclipse Lunar** é um ecossistema de scripts desenvolvido especificamente para otimizar o tempo de estudantes que utilizam as plataformas da **"Sala do Futuro"**. 

Nossa missão é combater a carga excessiva de tarefas repetitivas através de automação inteligente. Basta inserir seu RA e Senha, e o sistema cuidará do resto de forma totalmente autônoma.

### 🟣 Por que o Eclipse Lunar?
* **Automação Eficiente:** Realiza suas tarefas automaticamente sem necessidade de supervisão constante.
* **Acesso Simplificado:** Interface intuitiva focada na experiência do usuário.
* **Segurança:** Base de código revisada para garantir a integridade dos seus dados.
